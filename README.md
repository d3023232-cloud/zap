# ⛽ ЗАПРАВКА — Telegram Bot для BotHost

Экономический симулятор АЗС. Игроки управляют заправочными станциями, закупают топливо, устанавливают цены, нанимают персонал и строят топливную империю.

## 🚀 Установка на BotHost

1. Загрузите все файлы бота в корень проекта
2. Установите зависимости: `pip install -r requirements.txt`
3. В панели BotHost задайте переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_ID` — ваш Telegram ID (число)
4. Запустите: `python main.py`

## 📁 Структура

```
azs_bot/
├── main.py              # Точка входа
├── config.py            # Конфиг (читает env хостинга)
├── database.py          # SQLite — файл azs_bot.db
├── keyboards.py         # Кнопки
├── texts.py             # Тексты
├── requirements.txt     # aiogram + aiosqlite
├── handlers/
│   ├── start.py         # Регистрация, админка
│   ├── station.py       # Управление АЗС
│   └── top.py           # ТОП-10 рейтинг
└── services/
    ├── economy.py         # Экономика
    ├── events.py          # События
    └── scheduler.py       # Фоновые задачи
```

## 🔧 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать игру |
| `/admin` | Панель администратора |

## 💾 База данных

SQLite (`azs_bot.db`) — файл рядом с ботом. Не требует отдельного сервера.

## 👑 Администрирование

- Выдать/забрать деньги
- Выдать/забрать топливо
- Изменить репутацию АЗС
- Поиск игрока
- Список админов
